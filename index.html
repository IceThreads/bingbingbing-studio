尚未导入音乐

三步：① 拖入歌曲 → ② 选好截取起点/长度 → ③ 点「自动编曲」。 「音高」选 **旋律（扒谱）** 才会去提音高、把谱子扒出来；「单调」是把每个节奏点都打在同一个音上， 只扒节奏、不扒音高（原梗那种“冰冰冰”就是这个味道）。 灵敏度越大越严格（漏掉弱音），越小越容易把杂音也当成节奏；「节奏密度」可以只保留 1/8 或 1/4 的起音，结果更清爽。 没有歌可以点「用示例曲试一次」，程序会现场合成一段 100 BPM 的小曲、按「旋律」模式扒一遍给你看。

网格

钢琴卷帘：一行一个音高（C4 ~ C6），点格子开/关、按住拖动连续涂抹、点音名试听那一行。
每个音符都带时值和力度（相当于 MIDI 的 note on/off + velocity）： 浅色尾格是时值延音；Shift+点把音拉长一格、Alt+点 或 右键缩短一格； 力度大的格子更亮、力度小的更暗。时值长的音会真的响更久（两拍以上的音中途会自动补轻击）。

尚未载入采样

想让工作室内置这段素材、双击就能用？执行 py tools/embed-sample.py "音频路径"

「音高感」= 在素材上叠一层按音符频率衰减的正弦体。原素材每个“冰”只有一百多毫秒， 纯靠它听不出音高，旋律会变成一串“哒哒哒”；调到 0 就是纯素材原味，调到 0.6 以上旋律最清楚。

载入时会自动裁掉素材前后的静音，并按能量切出每个“冰”字的位置；「单个冰」只发第一段（琴键手感更跟手），「整段冰冰冰」则一次把三个字打出来。

保存与导出

导出的 WAV 为 44.1kHz / 16bit 立体声，直接可用于视频剪辑。 导出的 MIDI 是标准 SMF 格式（含 tempo、时值、力度），可以直接拖进 DAW / MuseScore。

整首歌的 MIDI 动辄几千格，网格装不下，所以要分段导入：选文件后会先分析， 自动跳到第一个有音符的段落并按八度自动移调，然后你可以用「下一段」一段段听。
